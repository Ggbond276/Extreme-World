## 🤔 面试官可能问的"边界题"

### Q:为什么没做完所有任务类型?

**A**:这是学习项目,优先实现**最常见的传统任务流程**(接 / 做 / 奖 / 存),其他类型是配置扩展,不改架构。**架构已经支持扩展**(新增目标类型只需加枚举值 + UI 提示)。

### Q:你会不会觉得任务系统做得不够?

**A**:够不够看**目标用户**和**时间投入**。对于"完整跑通 MMO 客户端/服务端协作"这个目标,我们的任务系统已经展示了所有关键模式(数据分层 / RPC / 状态机 / 持久化 / 同步)。**缺的特性都是工程量,不是架构问题**。

### Q:下次你会优先做什么?

**A**:**事件总线**。这是把"业务"和"数据"解耦的关键一步,做完后:
- 怪物死亡 → 任务进度自动推进
- 物品获得 → 收集类任务自动推进
- 等级提升 → 自动开放新任务(取代硬编码)

事件总线是**整个游戏系统升级的瓶颈**,不是任务系统单独的瓶颈。
